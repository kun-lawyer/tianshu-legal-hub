# 特殊证据质证清单

对方证据里有电子数据、证人证言、鉴定意见，或处在二审、再审程序时读本文件。只用于找质证切入点；对外质证意见的结构、措辞按你自己的质证意见模板（没有就按 SKILL.md 第 4 节的写法），不按本文件的分类逐项铺开。

条号均于 2026-11-08 经北大法宝详情接口核对（证据规定为 2019修正，民诉法解释为 2022修正，民诉法为 2023修正）。法律会修订，写进对外稿前仍须到权威法规数据库现查原文。

## 一、通用落点

- 三性之外先看**能不能单独定案**：证据规定第90条列了五类不能单独作为认定根据的证据（当事人陈述、与年龄智力不相当的限制行为能力人证言、与一方有利害关系的证人证言、**存有疑点的**视听资料和电子数据、无法与原件核对的复制件）。电子数据只有"存有疑点"才落入该条，不能写成"单一电子证据不能定案"。
- 私文书证：签名、盖章或捺印的推定为真实（证据规定第92条第2款），**真实性的举证责任在提交方**（第1款）。对方单方制作、无我方签章的对账单、结算表，攻真实性和证明力，不攻合法性。
- 非法证据排除的门槛是"严重侵害他人合法权益、违反法律禁止性规定或者严重违背公序良俗"（民诉法解释第106条）。参与谈话的一方自行录音一般够不上这个门槛，主张排除前先掂量；攻点通常放在完整性（节选）和主体同一性。

## 二、电子数据

审查因素以证据规定第93条第1款七项为纲，推定真实的五种情形见第94条（含公证的内容，第2款）。对方证据落入第94条的，我方要拿出"足以反驳的相反证据"，单纯否认不够。

切入点：
1. 原始载体：直接来源于电子数据的打印件、输出介质视为原件（证据规定第15条第2款），所以"只交截图"本身不是攻击点。攻的是能否证明截图直接来源于原始数据：要求当庭登录原始账号、原始设备展示，对不上或拒不展示的，再转入第90条第四项"存有疑点"。
2. 完整性：聊天、邮件是否被节选；缺了哪段上下文，那段对我方有利在哪里，最好我方自己出示完整记录。
3. 主体同一性：账号、手机号、邮箱能否对应到被主张的主体（实名信息、长期使用记录）。
4. 时间：显示时间与待证事实的时间节点是否吻合，有无事后补做的迹象。
5. 形成环境：是否在正常往来中形成（第93条第1款第五项）；临诉前集中生成的，证明力存疑。

## 三、证人证言

1. **出庭**：无正当理由未出庭的证人以书面等方式提供的证言，不得作为认定案件事实的根据（证据规定第68条第3款）。这是最硬的一条，优先用。不出庭的正当理由要申请、要准许（第76条）。
2. **作证方式**：只陈述亲身感知，不得猜测、推断、评论；作证前不得旁听庭审，不得宣读事先准备的书面材料（第72条）。转述他人所言、旁听后作证、念稿作证，都从这里切。
3. **资格**：不能正确表达意思的人不能作证（第67条）。
4. **利害关系**：与一方或其代理人有利害关系的证言不能单独定案（第90条第三项）；员工、亲属、合作方逐一点明具体关系，不写"存在利害关系"了事。
5. **保证书**：拒绝签署或者宣读保证书的不得作证（第71条第3款）。

## 四、鉴定意见

1. **鉴定书形式**：对照证据规定第36条七项内容（委托法院、委托内容与要求、鉴定材料、原理方法、过程说明、鉴定意见、承诺书）及鉴定人签名、资格证明、机构盖章，缺项即为切入点。
2. **异议程序**：在法院指定期间内书面提出（第37条第2款）；收到书面答复后仍有异议的，法院通知预交出庭费用并通知鉴定人出庭，**不预交视为放弃异议**（第38条）。提异议时一并安排预交。
3. **重新鉴定**：四种应当准许的情形见第40条第1款（资格、程序严重违法、明显依据不足、其他不能作为证据使用）；瑕疵能通过补正、补充鉴定、补充质证解决的不予准许（第3款）。申请重新鉴定要落到这四项之一，不要只说"结论不公"。
4. **单方委托意见**：对方自行委托出具的意见不是司法鉴定，我方有证据或理由足以反驳的，可以申请鉴定（第41条）。
5. 实质内容：检材来源与确认、方法是否适用于本案对象、结论是否或然（"不排除""倾向于"）、是否超出委托范围、是否以鉴代审回答了法律问题。

## 五、二审、再审新证据

1. **逾期举证**：先要求对方说明理由（民诉法第68条第2款，民诉法解释第101条第1款）。因客观原因逾期或我方未提异议的，视为未逾期（解释第101条第2款），所以**发现逾期必须当庭提出异议**，否则这道防线自动失守。
2. **后果**：故意或重大过失逾期的不予采纳，但与案件基本事实有关的仍应采纳并训诫、罚款（解释第102条第1款）。对方证据涉及基本事实的，只攻逾期挡不住，必须同时攻实质。可主张对方赔偿因逾期增加的必要费用（第3款）。
3. **再审新证据**：现行事由是民诉法第211条第（一）项。民诉法解释第385条原文仍写"第二百零七条第一项"，引用时改述为现行第211条（新旧条号未同步，易引错）。理由成立的三种情形见解释第386条第1款：庭审结束前已存在但因客观原因事后才发现、已发现但因客观原因无法取得、庭审结束后形成且无法另行起诉。
