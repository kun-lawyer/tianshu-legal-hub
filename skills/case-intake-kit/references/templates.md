# 开案五件套模板（源自作者既往定稿，2026-06-30）

占位符用 `〔〕` 标注。生成时逐项替换；用户未提供的信息保留 `〔待补：XX〕` 原样输出，禁止编造。律所名称、承办律师、联系电话从执业档案读，没有档案就保留占位。

委托代理合同的收费、解约、管辖条款是作者所在律所的惯用写法，使用前请按你所在律所的格式合同和当地律师收费规定调整。

## 01. 委托代理合同

```
委 托 代 理 合 同

甲方一：〔委托人一全称〕
住所地：〔住所地〕
法定代表人：〔法定代表人〕（单位委托人才有此行）
统一社会信用代码：〔信用代码〕（单位委托人才有此行；自然人改为：身份证号码、联系电话）

甲方二：〔委托人二，无则整块删除〕

乙方：〔律师事务所全称〕

甲方因与〔对方当事人〕〔案由〕一案（案号：〔案号〕，〔受理法院〕受理），委托乙方律师担任本案〔审理阶段〕诉讼代理人，经双方协商一致，达成如下协议：

一、乙方接受甲方委托，指派〔承办律师〕律师为甲方本案〔审理阶段〕诉讼代理人。甲方指定〔联系人〕为联系人，联系电话〔电话〕。

二、乙方律师应认真办理各项委托事项，依照法律维护甲方的合法权益。

三、甲方必须真实地向乙方律师叙述事实，提供与本案有关的证据材料。乙方接受委托后，发现甲方捏造事实、弄虚作假的，有权终止代理，所收费用不予退还。

四、本案委托标的为：〔诉讼请求金额及构成〕。

五、甲方委托乙方代理权限为特别授权，即乙方律师可在受托范围内代为承认、放弃、变更诉讼请求，进行和解，提起反诉、上诉。

六、代理费的收取方式：〔按用户选择填写，三种句式如下〕
（固定）甲方应于本协议签订后三日内一次性支付乙方〔阶段〕代理费〔金额〕元（人民币〔大写〕元整）。
（风险）本案以〔计算基数〕为基数，按〔比例〕计算风险代理费，于〔支付节点〕后十日内一次性支付。
（混合）（一）基本代理费：甲方应于本协议签订后三日内一次性支付乙方〔阶段〕基本代理费〔金额〕元（人民币〔大写〕元整）；（二）风险代理费：本案以〔计算基数说明〕为基数，按〔比例〕计算风险代理费，于〔支付节点〕后十日内一次性支付。
（通用尾句）乙方因办案所需的差旅费、交通费、鉴定费、保全费、公告费等均由甲方另行承担。

七、本合同有效期自双方签章之日起生效，至本案〔审理阶段〕诉讼阶段审理终止（包括判决、调解、案外和解、撤诉等）之日止。

八、如乙方无故终止合同，已收代理费全部退还甲方；如甲方无故终止合同，已支付的基本代理费不予退还。甲方在乙方开始各项代理工作之前终止本合同的，可不支付后续费用，但已支付的不得要求退还；甲方在乙方已开始各项代理工作后终止本合同，或案件以撤诉、调解、庭外和解等方式终结的，均视为乙方代理义务的全部履行，甲方不得索回已付代理费，未支付或部分支付的，甲方应在终止之日起三日内向乙方补交。

九、本合同一式〔份数〕份，甲方、乙方各执一份，具有同等法律效力。因本合同发生争议，应协商解决；协商不成的，依法向乙方所在地有管辖权的人民法院起诉。

（签署栏，两栏表格）
甲方一（盖章）：〔单位〕            乙方（盖章）：〔律师事务所全称〕
甲方二（签字）：〔个人〕            承办律师：〔承办律师〕
日期：    年   月   日              日期：    年   月   日
```

## 03. 补充材料清单（骨架，逐项结合本案定制）

```
补充材料清单

案号：〔案号〕　〔案由〕
致：〔委托人〕

为准备答辩状及举证，请于举证期限（〔举证期限日期〕）前提供以下材料：

一、委托手续材料
（单位）营业执照副本复印件、法定代表人身份证复印件、授权委托书（特别授权，加盖公章）
（个人）身份证复印件、授权委托书（特别授权，本人签字）

二、〔本案核心争点相关的身份 / 资格材料，写明为什么要〕

三、合同与结算材料
〔合同原件、结算单、供货 / 履行凭证，按本案列明〕

四、付款凭证材料
〔逐笔列明需核对的付款事实〕

五、〔本案关键争议文件原件及签订过程材料〕

六、其他
双方往来催款函、微信、短信、通话记录等沟通材料
对方资产、涉诉情况说明，供评估和解可行性
〔关联案件进展〕

如部分材料暂时无法提供，请说明原因及可补充的时间，以便合理安排举证及答辩工作。
```

## 02. 案件分析报告（结构要求，正文按案情写）

一、案情梳理与时间线
二、法律关系
三、争议焦点
四、双方主张与攻防预判（模拟对方与法官）
五、风险与胜负态势（定性表述，禁百分比）
六、办案思路建议
七、下一步动作清单（含期限）
