# mode: intake（接案初评）

> 合并自 `litigation-intake-assessment`。原 skill 未集成守则且量化胜诉率，本规程已修正这两点。

## 什么时候用

接案前的初筛：这个案子值不值得接、能不能打、成本多少、证据够不够。**尚未建立工作区**，输出是给主办律师和客户共用的一份决策材料。

已经接了案子要做深度分析走 `analyze`，要定打法走 `strategy`。

## 输入

必需：
- 基本事实经过（当事人怎么讲的）
- 我方拟担任的立场（原告 / 被告 / 申请人 / 被申请人）
- 诉求或应诉目标

有则更好：
- 初步证据材料清单
- 对方主体信息（法人用你可用的企业信息查询渠道核验，如天眼查、企查查、国家企业信用信息公示系统；用完整登记名或统一社会信用代码查）
- 管辖法院或仲裁机构
- 客户对成本与周期的预期

材料不全时**不要拒绝分析**，按守则 A8 处理：明说缺什么、缺失如何影响判断、在此前提下给出初步意见。

## 工作步骤

### 1. 事实固定

把当事人的口头陈述转成可核验的事实条目。每条标注来源：

| 事实 | 来源 | 可核验性 |
|---|---|---|
| 2024-03 出借 50 万元 | 当事人陈述 | 待转账凭证印证 |
| 借条载明月息 2% | 已见借条复印件 | 需核原件 |

**当事人陈述不等于事实**（守则 A10）。凡影响结论的关键陈述，标明它现在只是陈述，需要什么来印证。

### 2. 法律关系识别

- 基础法律关系是什么（借贷 / 买卖 / 承揽 / 劳动 ...）
- 有无竞合（违约与侵权、合同无效与撤销）
- 我方是权利人还是义务人

### 3. 请求权基础初筛

列出可走的请求权路径，每条写明核心要件与我方现有材料的匹配度：

| 路径 | 请求权基础 | 要件缺口 | 可行性 |
|---|---|---|---|
| A | 民法典 667 条借款合同 | 缺实际交付证据 | 🟠 |
| B | 不当得利返还 | 需证明无法律原因 | 🟡 |

法条引用走守则 A6 自检与 A7 原文纪律，未取到原文的不替条文做描述（守则 A11）。

### 4. 证据短板与补证路径

| 待证事实 | 现有证据 | 短板 | 补证路径 | 难度 |
|---|---|---|---|---|
| 实际交付 | 无 | 🔴 致命 | 银行调流水 | 中 |

🔴 级短板必须单独提示：**它是不接案或先补证再立案的理由**。

### 5. 时效与期限

按 [time-discipline.md](time-discipline.md) 计算。接案初评阶段最关键的是：

- 诉讼时效是否已过或临近（3 年一般时效，起算点写清）
- 若是应诉：答辩期与举证期还剩多少（带算式）
- 有无除斥期间、申请再审的 6 个月窗口等硬性节点

时效已过或剩余不足 7 天的，**在报告最前面单独成段**，不能埋在正文里。

### 6. 成本与周期估算

给区间不给点值，并写明估算依据：

| 项 | 估算 | 依据 |
|---|---|---|
| 诉讼周期 | 一审 4 至 8 个月 | 普通程序 6 个月，本地法院实际排期 |
| 诉讼费 | 约 X 元 | 标的额 Y 元，按财产案件受理费标准 |
| 律师费 | 按你的报价标准给区间 | 所内收费标准或客户档案（如有） |
| 执行风险 | 🟠 | 对方有无可供执行财产未查 |

**执行风险必查必写。** 赢了执行不下来等于没赢，这是接案初评最容易漏的一项。

### 7. 接案结论

定性表达，禁百分比（见 SKILL.md「胜诉预判口径」）。结论落在四档之一，后面必须跟理由：

```
✅ 建议接：借贷关系有借条与微信记录双重印证，主要风险在实际交付举证，
   补一份银行流水即可闭合。对方名下有房产，执行有着落。
✅ 建议补证后再接：核心的实际交付事实目前只有当事人陈述，
   在拿到流水前立案有败诉风险。
✅ 谨慎：诉讼时效距届满仅 40 天，且关键证人不配合。
✅ 不建议接：时效已过 8 个月，对方明确会抗辩，无中断中止事由。
```

## 输出格式

文件名：`YYMMDD 接案初评.md`（未建工作区时输出到当前目录，建了则进 `产物/`）

```markdown
# [案件简称] 接案初评

> ⚠️ 复核须知
> - **来源**：[标注每类信息来源]
> - **已读**：[材料结构清单]
> - **待复核**：N 处 [review]
> - **时效性**：核对了 [法条] 现行有效性
> - **视角**：拟按 [立场] 承办
> - **分析基准日**：YYYY-MM-DD

## 〇、时效与硬期限提示
[已过或临近的单独成段；无则写"经核，本案无临近期限"]

## 一、事实固定
## 二、法律关系
## 三、请求权基础初筛
## 四、证据短板与补证路径
## 五、成本与周期
## 六、执行风险
## 七、接案结论（定性 + 理由）

## 八、决策树
> **接下来怎么走？请选一个：**
> 1. **接案并建档** 我跑 setup 建工作区，归档材料，生成期限表。
> 2. **先补证再定** 我列出取证清单和调查令申请要点。
> 3. **先发律师函试探** 我起草律师函（有律师函类 skill 就用它，没有就按律师函通用格式写：受函人、事实、法律依据、要求与期限、律所落款）。
> 4. **出具不接案说明** 我起草给客户的书面说明。
> 5. **要更深的分析** 我跑 analyze 做案情建模。
> 6. 其他

## 九、清单之外的一问
> [典型：对方有没有可供执行财产？有没有关联案件正在审？]
```

## 与旧 skill 的差异

| 项 | litigation-intake-assessment | 本模式 |
|---|---|---|
| 胜诉率 | 量化百分比 | 定性四档 + 理由 |
| 守则 | 未集成 | 全套 |
| 时效计算 | 无强制算式 | 强制算式 + 单独成段 |
| 执行风险 | 未强制 | 必查必写 |
| 后续衔接 | 无 | 决策树直通 setup |
