# 公文排版：格式规范参考

> 本文档为格式规范的参考说明。实际排版操作由 `scripts/format_gongwen.py` 脚本自动完成。

## 一、字体规范

### 1. 标题字体（方正公文小标宋）

- 字体: 方正公文小标宋（ascii/hAnsi/eastAsia/cs 全部设为方正公文小标宋）
- 字号: 二号 = sz val="44", szCs val="52"
- 加粗: w:b + w:bCs
- 对齐: 居中 (w:jc val="center")
- 识别条件: 居中 + sz >= 36

### 2. 正文字体（仿宋_GB2312 + Times New Roman）

- 中文字体: 仿宋_GB2312 (eastAsia)
- 西文字体: Times New Roman (ascii/hAnsi)
- hint: eastAsia
- 适用范围: 称呼行、正文、一级/二级标题、签名

## 二、字号规范

- 统一字号: 四号 = 14pt = sz val="28"
- 标题字号例外: sz val="44" 不替换
- szCs 在非标题段落中移除

## 三、缩进规范

| 段落类型 | firstLine | firstLineChars |
|----------|-----------|----------------|
| 正文 | 560 | 200 |
| 一级标题 | 562 | 200 |
| 二级标题 | 560 | 200 |
| 称呼行 | 无缩进 | 无 |
| 签名 | 无缩进 | 无 |

## 四、行距和段间距

- 行距: 固定值 28 磅 = 560 twips → `w:line="560" w:lineRule="exact"`
- 段前/段后: 默认清除（去除 w:before / w:after）
- 例外: 签名区域保留 `w:before="600"` 或 `w:before="400"` 用于留白

## 五、页面设置

| 属性 | 值 (DXA) | 说明 |
|------|----------|------|
| pgSz w | 11906 | A4 宽 |
| pgSz h | 16838 | A4 高 |
| pgMar top | 1440 | 上边距 2.54 cm (1 inch) |
| pgMar bottom | 1440 | 下边距 2.54 cm (1 inch) |
| pgMar left | 1800 | 左边距 3.18 cm (1.25 inch) |
| pgMar right | 1800 | 右边距 3.18 cm (1.25 inch) |
| header | 851 | 页眉距边界 |
| footer | 992 | 页脚距边界 |
| gutter | 0 | 装订线 |
| cols space | 720 | 分栏间距 |
| cols num | 1 | 单栏 |
| docGrid linePitch | 360 | 网格行距 |
| docGrid charSpace | 0 | 网格字距 |

## 六、特殊元素处理

### 装饰性段落
- 包含 `w:pBdr` 的空段落（分隔线）应删除

### 标题后空行
- 在最后一个标题段落后插入空段落
- 空行字体: 仿宋_GB2312 + Times New Roman, sz=28

### 签名区域
- 保持右对齐 (w:jc val="right")
- 去除行距设置
- 保留 w:before 留白间距

## 七、段落类型识别逻辑

| 类型 | 识别条件 |
|------|----------|
| 标题 | 居中 + sz >= 36 |
| 签名 | 右对齐 |
| 一级标题 | 文本匹配 `^[一二三四五六七八九十]+、` |
| 二级标题 | 文本匹配 `^[（(][一二三四五六七八九十]+[）)]` |
| 称呼行 | 标题后首个非空非缩进段落 |
| 正文 | 其余段落 |

## 八、处理顺序

脚本 `format_gongwen.py` 按以下顺序执行：

1. 设置页面参数 (sectPr)
2. 分析文档结构，分类所有段落
3. 处理标题段落
4. 插入标题后空行
5. 处理称呼行
6. 处理正文、一级标题、二级标题、签名
7. 清理装饰元素
8. 处理 styles.xml
